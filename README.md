
# Week 8 - My Python Toolkit

## Project Description

My Python Toolkit is a program containing three useful tools.

### Tools
1. Number Guessing Game - Allows users to guess a secret number.
2. To-Do List - Allows users to add, view and remove tasks.
3. Simple Calculator - Performs addition, subtraction, multiplication and division.

## How to Run

1. Open the repository.
2. Download the toolkit.py file.
3. Run it using Python:
   python toolkit.py
4. Choose a tool from the menu.

## Reflection

The hardest part of this assignment was creating the menu loop and making all three tools work together. The bug that took the longest to fix was handling invalid choices and making sure the program did not crash. I learned how to use loops, conditionals and lists. I also learned how to organize code using functions. The to-do list helped me understand how lists can change while a program is running. If I had one more week, I would add more tools and improve the menu design. I am happy that I completed my Python Toolkit.
